### Performance History JavaScript Bugs (13:17)
**Problem:** All fields showing "undefined" in Performance History table  
**Root Cause:** JavaScript used `row.total` instead of `row.total_games`, no undefined checks  
**Fix:**
- Changed all `row.total` to `row.total_games` (3 occurrences in server.py line 2703, 2715, 2716)
- Added undefined checks for `avgDoom`, `avgSBs`, `avgAPs`, `avgScore`, `type`
- Added expandable faction breakdown rows (click to show per-faction stats)
**Files:** `server.py` lines 2702-2745

### Rebuild Script Case-Sensitivity Bug (13:20)
**Problem:** rebuild_canonical_clean.py wiped all R40 data, Game Browser loading nothing  
**Root Cause:** Script looked for "Result: WIN" (uppercase) but R40 traces have "Result: win" (lowercase)  
**Fix:**
- Changed regex from `r'Result: (WIN|LOSS)'` to `r'Result: (WIN|LOSS|win|loss)'` with `re.IGNORECASE`
- Changed `result_match.group(1) == 'WIN'` to `result_match.group(1).upper() == 'WIN'`
**Files:** `rebuild_canonical_clean.py` lines 189, 199
